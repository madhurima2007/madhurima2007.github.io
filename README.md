- Responsive Design
- Dark / Light Mode
- Smooth Scrolling
- Animated Sections
- Modern UI/UX
- GitHub Pages Deployment

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Deployment

```bash
git clone https://github.com/username/username.github.io.git
git add .
git commit -m "Initial deployment"
git push origin main
```

Enable GitHub Pages:

Settings → Pages → Deploy from Branch → main → root
